# 📱 Mobile Sales Dashboard

## Overview

An interactive Power BI dashboard developed to analyze mobile sales performance using Power BI, DAX, and Power Query.

## Dashboard Features

- Total Sales
- Total Quantity
- Transactions
- Average Price
- Sales by City
- Customer Ratings
- Mobile Model Sales
- Payment Method Analysis
- MTD Analysis
- Same Period Last Year Analysis

## Tools Used

- Power BI
- DAX
- Power Query
- Excel
